Method · version 2026-10-14.4

How your case becomes a guidance result.

The case tool applies published recommendations to a limited set of recognized details. The text rules, their order and the conditions described here are software design choices. They have not been independently validated as a clinical decision instrument.

Information used

The tool uses your current description and the main reason you select for wanting additional information. Any details to confirm appear inside the highlighted result box, above the reason choices. Selecting a reason updates the guidance and returns you to the result heading. It recognizes selected terms, common abbreviations and some negative statements. It cannot fully understand an unrestricted clinical narrative.

Capitalization, repeated spaces, common contractions and 2-D/3-D spelling are normalized before the text checks. Explicit family-history statements and remote history explicitly marked unrelated are excluded from topic matching; the explanation records that exclusion. This does not mean that medical or family history is irrelevant to the clinician. Other past events remain visible and may prompt clarification of the current question.

The starting assumptions are: the patient’s history has been reviewed, the examination is complete, relevant 2D X-rays have been taken and reviewed, and no CBCT has been taken for this question. These are workflow assumptions, not verified facts. The result explanation distinguishes assumptions from reported details. Recognized statements about an incomplete assessment, absent or unreviewed 2D images, sufficient 2D images, or a previous CBCT take priority. Users should correct assumptions in their descriptions.

Assuming a 2D review does not establish that those images are inadequate. For a non-implant pathway, if their ability to answer the question is unclear, the tool asks what information remains missing. Implant planning does not require failed 2D imaging. The starting-point notice calls for history and examination first and appropriate initial 2D imaging when needed; it does not instruct users to obtain new 2D images in every case.

All case processing takes place in the browser. Descriptions and follow-up answers are not sent to a model, searched online, stored in the analytics database or saved between visits. Usage measurement records tool activity and timing, not case content. Editing the description clears follow-up answers to prevent them carrying into a different case.

Apart from the stated starting assumptions, missing information remains unknown. Study percentages, scan-estimator counts, fees and revenue assumptions never contribute to a clinical result. The old wording-match score does not decide the displayed guidance category.

How the selected reason affects the result

The options represent common practical purposes, not a complete list of clinical indications. Selecting a reason never creates a diagnosis, supplies a missing anatomical question or adds a topic to the source library.

Choices related to the question recognized in the description appear first. All choices remain available, including “Another reason or not sure yet,” and none is preselected. The order stays the same while answers change; it is based on the description, not on which answer produces a supportive result. It is a navigation aid, not a recommendation to choose a procedure.

  • Understanding findings, locating a problem, choosing treatment, assessing risk or investigating complications: these establish a stated potential use for additional information. A supportive result still requires a covered case and the relevant pathway conditions. A complication or nearby-structure risk selection needs corresponding details in the description; a diagnostic-purpose selection with only a planning question needs clarification.
  • Implant planning: this separate choice requires implant planning in the description and a site measurement or anatomical relationship needed for placement. Selecting it cannot turn unexplained tooth pain into an implant-planning case.
  • Another treatment procedure: the description must name a proposed procedure and specific information needed to plan it. Recognized procedures include root canal treatment, retreatment, root-end surgery and extraction within the existing source coverage. Past or denied treatment does not establish a new plan. Generic planning language or an inconclusive image alone is insufficient. Unrecognized procedures and mismatches prompt clarification; they do not expand coverage.
  • Healing concerns: the description must identify a clinical concern. The persistent endodontic disease pathway may apply; other healing questions need clarification or separate guidance. Routine follow-up is not an automatic CBCT indication.
  • Referral: the tool asks which unanswered finding would change the referral and notes that the receiving clinician may be best placed to select further imaging.
  • Routine screening or baseline imaging, patient request or reassurance, documentation only, or no expected change in care: these purposes alone produce a “not supported” result. A separate diagnostic or treatment question must be described and assessed separately.
  • Another reason or uncertainty: the tool asks for the intended decision and does not infer a benefit.

The categories and their routing are this tool’s implementation of patient-selection principles, not a validated questionnaire or a numbered list from a guideline. They use the existing clinical source map; no new clinical indications were added by this interface change.

The checks, in order

  1. Can this description be assessed? Empty or excessively long descriptions need revision. A few explicit urgent presentations, such as breathing or swallowing difficulty or significant head-injury symptoms, stop ordinary CBCT guidance and direct the clinician to urgent assessment. This is a limited safety check, not an emergency triage system: an absent notice does not establish that the case is non-urgent. Hypothetical cases, primary dentition or an explicitly different tooth-numbering system need clarification. Numbers otherwise use the Universal permanent-tooth system. More than one tooth number, contradictory key findings, or separate recognized purposes require clarification. This version does not reliably assign every finding to its tooth or time point.
  2. Is the selected purpose sufficient on its own? A screening, reassurance, documentation-only or no-change selection receives a negative purpose result. This does not assess a separate clinical indication that may also be present in the description.
  3. Is the question covered? Recognized topics outside the library receive a coverage notice. An unfamiliar or vague description receives a clarification request. Neither result means CBCT is inappropriate. A practical reason cannot remove this coverage limit.
  4. Is there a supported purpose? Routine screening and sleep-apnea diagnostic requests have dedicated notices. A separate dental question must be described separately.
  5. Which pathway applies? Explicit procedure and condition language selects a pathway. Priority is implant planning, endodontic surgery, third-molar assessment, impaction, resorption, retreatment, root fracture, cracked tooth, trauma, dental-source sinusitis, persistent endodontic symptoms, then unclear tooth symptoms. This is routing order, not clinical urgency or evidence strength.
  6. Do the details agree? Contradictory imaging statements or a stated potential benefit that conflicts with an explicit report of no benefit stop the result. A selection cannot silently override conflicting clinical facts.
  7. Do existing images already answer the question? Reported adequate CBCT or images still needing review take priority. Reported sufficient 2D images or no added benefit prevents a supportive result for that same question.
  8. Is a scan already being arranged, or does the text describe a past plan? A recognized existing order prompts coordination with the requesting clinician. Past trauma, completed surgery or an earlier plan cannot establish a current imaging question by themselves. General words such as “size” or “width” do not count as site measurements without relevant anatomical wording.
  9. Are the application conditions established? A supportive result uses the stated history, exam and 2D-review assumptions unless the description contradicts them. It also requires a recognized relevant question and potential effect on care. Reported pending clinical testing still needs attention. Missing criteria produce targeted questions. Other pathways with no imaging available prompt consideration of initial lower-exposure assessment.

The result displays the selected pathway, the details used, their origin (description, selected answer or default assumption), the rule identifier, version and source links. A selected answer fills a gap; it does not verify the underlying clinical facts.

What the outcomes mean

OutcomeMeaning
Guidance supports considerationThe recognized details satisfy this software pathway. This does not establish a diagnosis, prescribe a scan, determine exposure settings or guarantee benefit.
Confirm details firstA covered question was recognized, but conditions still need confirmation. The recommendation remains visible beside the missing details.
Review existing imagesThe description reports an existing CBCT. Its usefulness for the current question takes priority over another scan.
Purpose not supported as describedA specific reason prevents support for the stated purpose, such as routine screening or an explicit report that no additional information is needed. This does not exclude a different justified question.
Clarification neededThe description is ambiguous, conflicting, spans different contexts, or does not identify a question reliably.
Outside current coverageThe tool recognized a topic it cannot assess. This is a library limitation, not an assessment of the published evidence for that condition.

Review and limits

Software mapping updated on October 14, 2026; the ADA’s patient-selection overview was rechecked for the starting-point wording. This is a source-mapped software review; independent clinician review remains pending. Automated cases check behavior—including denials, missing context and repeat imaging—but do not establish clinical accuracy or safety across unrestricted inputs.

The parser can miss synonyms, abbreviations, negation, time changes and tooth relationships. It does not inspect images, verify diagnoses or assess all patient-specific considerations. A normal 2D report alone is not treated as proof that a clinical question is answered. No result is a probability or a diagnostic confidence percentage.

General TMJ, jaw pathology, orthodontic, periodontal and implant follow-up or complication recommendations require separate reviewed pathways before being added. An implant complication cannot inherit an endodontic complication pathway. A source update should be accompanied by revised rule mapping and tests, followed by clinical review.

Apical periodontitis in an endodontic case is distinguished from general periodontal disease. Implant planning with a recognized age below 18, or explicit child/adolescent wording, prompts review of source applicability. That age boundary is a software coverage choice, not a clinical threshold for implant treatment. The tool does not evaluate growth, treatment timing or pediatric implant exceptions.

The October 14 language audit added synthetic cases covering shorthand, conversational descriptions, background details, missing assessments, prior scans, past plans and purpose changes. This regression set tests defined software expectations; it is not an independent clinical validation set and its pass rate is not a clinical accuracy percentage. Source applicability, uncommon wording, mixed histories and patient-specific considerations still need clinician review.
